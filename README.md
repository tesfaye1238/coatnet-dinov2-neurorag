# neurofusion

Manuscript-based research implementation of *"Attention-Guided CoAtNet-DINOv2 Fusion for Brain MRI Classification and Retrieval-Augmented
Reporting"*: a CoAtNet-0 + DINOv2 ViT-S/14 fusion classifier with squeeze-and-excitation recalibration, its ablations and baselines, a leakage-aware
data pipeline, evaluation and statistics tooling, Grad-CAM, a retrieval-augmented contextual-reporting module (NeuroRAG), a local Streamlit demo,
and an audit of the manuscript's own numbers.

> **Status: research code. Not clinically validated. No result in this repository is a measurement on the manuscript's data.**
> The code is a reconstruction from the manuscript; its correspondence to the authors' original experiment code is not established.
> No MRI data, weights, manuscript or reviewer correspondence are included. A completed training run would be a **new experiment**.

## What was found while building it

* The Zenodo record cited as the dataset (10.5281/zenodo.7786009) is a **trained-model record** with no images (see [data_provenance](docs/data_provenance.md)).
* The manuscript's numbers contain internal inconsistencies, regenerated by `neurofusion audit-manuscript`
  ([numerical_audit](docs/numerical_audit.md), [manuscript_discrepancies](docs/manuscript_discrepancies.md)): three baseline accuracies are not
  attainable on 1,600 images, the Section 6.1 narrative contradicts Table 4 and Figure 8, Figure 2's training counts sum to 5,712 against 4,782 in
  Table 1, Table 7B's source sizes conflict with the stated no-tumor provenance, and the McNemar statistics in Supplementary S5 imply discordant
  counts whose exact p-values change the significance of at least one comparison.
* Instantiated parameter counts are about 0.085 M above the reported ones while the differences between variants agree, which supports the SE
  layer sizes and a 384->768 projection for the summation ablation ([parameter_audit.json](docs/parameter_audit.json)).

## Install

```
python -m venv .venv && . .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install torch torchvision                            # choose the build for your hardware
pip install -e ".[dev,app]"                              # core + tests + demo
pip install -e ".[mat]"                                  # figshare .mat import
pip install -e ".[rag]"                                  # Qdrant, sentence-transformers, transformers, pypdf
```

`requirements-lock.txt` pins what was tested (see [reproducibility](docs/reproducibility.md)).

## Quick start

```
neurofusion env
neurofusion registry
neurofusion audit-manuscript --out docs/numerical_audit.md
neurofusion audit-parameters
neurofusion rag-demo-collection --out rag_sources/demo
neurofusion rag-build --sources rag_sources/demo/source_manifest.csv --allow-demo --out rag_index
neurofusion rag-generate --index rag_index --category glioma --confidence 0.93
streamlit run app/streamlit_app.py
```

The full command list (data, splits, training, seeds, cross-validation, evaluation, paired comparisons, Grad-CAM, robustness, efficiency, RAG
and reporting) is in [docs/reproducibility.md](docs/reproducibility.md). Every command shown is implemented in `src/neurofusion/cli.py`; the data, split,
evaluation, comparison, RAG, audit, training, prediction, Grad-CAM, robustness and efficiency commands are exercised by CLI tests
(`download-figshare`, `import-figshare`, `seeds` and `cv` are tested at function level only).

## Layout

| Path | Contents |
|---|---|
| `src/neurofusion/data` | source registry, figshare import, manifests, dedup, grouping, splits, transforms |

| `docs/` | provenance, architecture, protocol, RAG, discrepancies, decisions, evidence matrix, limitations |

## Verification performed

`pytest`: **162 passed**, coverage **92%** of project code (branch coverage on; measured with `pytest --cov=neurofusion`), `ruff` clean, sdist and
wheel build. All tests use **synthetic** fixtures; synthetic smoke-test outputs are not results. The real pretrained backbones were downloaded once
to verify the 768/384/1,152 dimensions and to record hub commits ([pretrained_provenance.json](docs/pretrained_provenance.json)).
