## A13 [FAIL] Table 7B source sizes vs dataset provenance

Table 7B uses source sizes figshare=3064, SARTAJ=3264, Br35H=694 (sum 7022 = the curated total). (i) Table 1 reports 1754 no-tumor images after screening, while the Zenodo record description says the no-tumor class came from Br35H; Br35H holds only 694 images here, which is fewer than 1754. (ii) The figshare collection has no no-tumor class (3 tumor classes only), so a 4-class macro metric on a figshare test source has an absent class. (iii) 218 duplicates were removed (Table 1) yet the figshare and SARTAJ subset sizes equal the full original collection sizes (3,064; the SARTAJ size is as stated by the manuscript). (iv) Br35H carries only binary tumor labels, so 4-class labels for that source need documented annotations. Manifests with source ids are required to resolve this.

## A16 [FAIL] Table S5 DeLong z for a macro (multiclass) AUC

The ordinary DeLong test is defined for a binary AUC. The manuscript gives one z and p for 'macro-AUC' without describing a multiclass extension; it cannot be reproduced or validated without the original procedure and probabilities. This repository uses a paired bootstrap for macro-AUC differences.
